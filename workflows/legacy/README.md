# Legacy Workflows Collection

This directory contains legacy/superseded workflow files from earlier iterations of the `ComfyUI-CcC-Krea2` suite.

> [!NOTE]
> These workflow files target earlier node contracts and socket interfaces. They are retained for backward compatibility and reference. For active production use, refer to the canonical numbered modular workflows in the parent `workflows/` directory (`01_t2i_basic.json` through `12_full_pipeline_composition.json`).

## Legacy Workflows Index

- `text_to_image.json`: Legacy text-to-image pipeline.
- `subject_edit.json`: Legacy single-subject reference workflow.
- `subject_scene.json`: Legacy subject + scene reference workflow.
- `subject_outfit.json`: Legacy subject + outfit reference workflow.
- `subject_outfit_scene.json`: Legacy triple-reference workflow.
- `subject_scene_qwen_simple.json`: Legacy Qwen-VL simple subject + scene workflow.
- `subject_scene_outfit_qwen_simple.json`: Legacy Qwen-VL simple triple-reference workflow.
